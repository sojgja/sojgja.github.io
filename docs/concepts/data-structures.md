# Data Structures

Các cấu trúc dữ liệu cơ bản trong lập trình:

- **Array** - mảng, truy cập O(1), thêm/xoá O(n)
- **Linked List** - danh sách liên kết, thêm/xoá O(1)
- **Stack** - ngăn xếp, LIFO
- **Queue** - hàng đợi, FIFO
- **Hash Table** - bảng băm, truy cập O(1)
- **Tree** - cây, dùng trong hệ thống phân cấp
- **Graph** - đồ thị, dùng trong mạng lưới

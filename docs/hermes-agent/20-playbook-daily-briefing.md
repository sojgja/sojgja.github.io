# Playbook · Daily briefing bot

Một bot thức dậy mỗi sáng, tự research chủ đề bạn quan tâm, tóm tắt và gửi bản briefing gọn
gàng vào Telegram/Discord. Không cần code — chỉ **web search + cron + delegation +
delivery**.

## 1. Luồng chạy {#luong}

```
08:00  Cron scheduler kích hoạt job
       Hermes mở phiên agent MỚI với prompt của bạn
       Web search lấy tin mới nhất
       Tóm tắt thành briefing gọn
       Delivery gửi tới Telegram/Discord
```

## 2. Chuẩn bị {#chuan-bi}

```
# Gateway chạy — daemon này thực thi cron
hermes gateway install                 # cài làm user service
sudo hermes gateway install --system   # Linux server: service lúc boot
hermes gateway                         # hoặc chạy foreground
```

- API key cho web search (ví dụ `FIRECRAWL_API_KEY`) trong `~/.hermes/.env`.
- Messaging đã cấu hình (tùy chọn) + **home channel**.
- Không có messaging vẫn được: dùng `deliver: local` → lưu ở
`~/.hermes/cron/output/`.

## 3. Bước 1: chạy tay, tinh chỉnh format {#thu}

Trong `hermes`, thử prompt:

```
Search for the latest news about AI agents and open source LLMs.
Summarize the top 3 stories in a concise briefing format with links.
```

Kết quả mẫu:

```
☀️ Your AI Briefing — 2026-09-26

1. Qwen 3 Released with 235B Parameters
   ...
   → https://qwenlm.github.io/blog/qwen3/

2. ...
---
3 stories • Generated by Hermes Agent
```

> **Quan trọng.** Đừng automate khi format chưa ưng. Thử các biến thể: "dùng header emoji", "mỗi tóm tắt dưới 2 câu". Thứ bạn chốt sẽ đi thẳng vào cron job.

## 4. Bước 2: tạo cron job {#cron}

**Cách A — ngôn ngữ tự nhiên (trong chat):**

```
Every morning at 8am, search the web for the latest news about AI agents
and open source LLMs. Summarize the top 3 stories in a concise briefing
with links. Use a friendly, professional tone. Deliver to telegram.
```

Hermes tạo job qua tool `cronjob_manage`.

**Cách B — slash command (kiểm soát hơn):**

```
/cron add "0 8 * * *" "Search the web for the latest news about AI agents and open source LLMs. Find at least 5 recent articles from the past 24 hours. Summarize the top 3 most important stories in a concise daily briefing format. For each story include: a clear headline, a 2-sentence summary, and the source URL. Use a friendly, professional tone. Format with emoji bullet points and end with a total story count."
```

## 5. Quy tắc vàng: prompt tự chứa {#quy-tac}

> **Khái niệm then chốt.** Cron chạy trong **phiên hoàn toàn mới** — không nhớ hội thoại trước, không biết bạn "đã set up cái gì". Prompt phải chứa *mọi thứ* agent cần.

| Prompt sai | Prompt đúng |
| --- | --- |
| "Do my usual morning briefing." | Nêu rõ *tìm gì*, *bao nhiêu bài*, *format nào*, *giọng nào* |

## 6. Tuỳ biến {#nang-cao}

### Đa chủ đề

```
/cron add "0 8 * * *" "Create a morning briefing covering three topics...

Topics:
1. AI/ML — open source models, agent frameworks
2. Crypto — Bitcoin, Ethereum, regulatory news
3. Space — SpaceX, NASA, commercial space

Format with section headers and emoji. End with today's date."
```

### Delegation cho research song song

```
/cron add "0 8 * * *" "Create a morning briefing by delegating research to sub-agents.
Delegate three parallel tasks:
1. Delegate: top 2 AI/ML stories from the past 24 hours with links
2. Delegate: top 2 crypto stories from the past 24 hours with links
3. Delegate: top 2 space stories from the past 24 hours with links
Collect all results and combine into one clean briefing with section
headers, emoji, and source links. Add today's date as a header."
```

Mỗi sub-agent tìm độc lập, song song; chỉ tóm tắt cuối quay về → tiết kiệm context & thời gian.

### Persona người đọc (tăng độ liên quan)

```
/cron add "0 8 * * *" "You are creating a briefing for a senior ML engineer who
cares about: PyTorch ecosystem, transformer architectures, open-weight models,
and EU AI regulation. Skip product launches or funding rounds unless open source.
Search the latest news, summarize top 3 with links. Be concise and technical."
```

### Lịch biến thể

| Nhu cầu | Biểu thức |
| --- | --- |
| Chỉ ngày thường | `0 8 * * 1-5` |
| Sáng + tối | Hai job `0 8 * * *` và `0 18 * * *` |
| Tổng kết tuần | `0 9 * * 1` |

## 7. Quản lý & vận hành {#van-hanh}

```
hermes cron list             # xem mọi job
hermes cron run <name>       # chạy ngay
/cron run <name>             # chạy từ trong chat
hermes pause / resume        # dừng/tiếp tục toàn cục
```

> **Best practice.** Thêm câu "Nếu không có gì đáng chú ý, trả lời `[SILENT]`" để tránh spam thông báo vào những ngày im ắng. Đặt home channel bằng `/sethome` để job có nơi gửi.

# Design Patterns — 23 mẫu thiết kế

**Design Patterns** là những giải pháp tổng quát cho các vấn đề thường gặp trong thiết kế phần mềm. Chúng không phải là code cụ thể, mà là những khuôn mẫu (template) có thể áp dụng linh hoạt.

## Phân loại

| Nhóm | Số lượng | Mẫu |
|------|---------|------|
| **Creational** (Khởi tạo) | 5 | Singleton, Factory Method, Abstract Factory, Builder, Prototype |
| **Structural** (Cấu trúc) | 7 | Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy |
| **Behavioral** (Hành vi) | 11 | Chain of Responsibility, Command, Interpreter, Iterator, Mediator, Memento, Observer, State, Strategy, Template Method, Visitor |

## Cách đọc

Mỗi pattern được trình bày theo cấu trúc:
- **Bài toán** — tình huống thực tế cần giải quyết
- **Giải pháp** — áp dụng pattern như thế nào
- **Ví dụ code** — code minh họa bằng JavaScript
- **Khi nào dùng** — dấu hiệu nhận biết nên áp dụng

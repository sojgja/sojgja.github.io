# Clean Code

**Tác giả:** Robert C. Martin (Uncle Bob)  
**Năm:** 2008  
**Thể loại:** Software Engineering

## Giới thiệu

*Clean Code* là cuốn sách kinh điển về cách viết code sạch, dễ đọc và dễ bảo trì. Uncle Bob đưa ra những nguyên tắc thực tế giúp lập trình viên chuyển từ "viết code chạy được" sang "viết code tốt".

## Nội dung chính

- **Tên biến có ý nghĩa** — đặt tên phải thể hiện rõ mục đích
- **Hàm nhỏ, làm một việc** — mỗi function chỉ nên làm đúng một việc
- **Comment là cần thiết nhưng ít càng tốt** — code tự giải thích tốt hơn comment
- **Error handling** — dùng exception, không dùng return code
- **Unit test** — viết test trước (TDD), giữ test sạch
- **Classes nhỏ** — Single Responsibility Principle

## Câu nói nổi tiếng

> *"Clean code always looks like it was written by someone who cares."*

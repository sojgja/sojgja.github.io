# Getting Started

Hướng dẫn bắt đầu nhanh với dự án.

## Yêu cầu

- Node.js 18+
- npm

## Cài đặt

```bash
npm install
```

## Chạy dev

```bash
npm start
```

## Build

```bash
npm run build
```
